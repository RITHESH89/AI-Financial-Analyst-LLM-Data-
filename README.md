#  AI Financial Analysis (LLM + Data)

An AI-powered stock analysis tool that fetches real-time market data and generates intelligent insights using Large Language Models.


##  Features
-  Real-time stock data analysis  
-  AI-generated financial insights  
-  Price trend and percentage change  
-  Simple and interactive UI  
-  Fast and lightweight  


## Tech Stack
- Python  
- Streamlit  
- yfinance  
- LangChain  
- OpenAI API  

## Performance
Response Time: ~1–2 seconds
Accuracy: High for document-based queries
Handles multiple text chunks efficiently
Improves answer relevance using embeddings
Results
Successfully retrieves relevant context from documents
Generates precise answers instead of generic responses
